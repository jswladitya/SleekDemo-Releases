# SleekDemo-Releases

Downloads and the automatic-update feed for **SleekDemo for Mac** — record your screen, camera and voice, then turn it into a polished demo with smooth auto zooms, cursor effects, captions and beautiful backgrounds.

## Download

Get the latest DMG from [Releases](https://github.com/jswladitya/SleekDemo-Releases/releases/latest), open it, and drag SleekDemo into Applications. Requires macOS 26 or later.

## Updates

SleekDemo checks this repository's `appcast.xml` and installs new versions with [Sparkle](https://sparkle-project.org). Every update is signed, so your Mac only installs builds that come from SleekDemo.
